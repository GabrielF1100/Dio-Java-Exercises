## 🎯 Conceitos-Chave Rápidos

1. **JVM (Java Virtual Machine):** A máquina virtual que executa o *bytecode* Java compilado.
2. **JRE (Java Runtime Environment):** Pacote para executar aplicações Java (inclui a JVM e bibliotecas padrão).
3. **JDK (Java Development Kit):** Kit completo para desenvolvedores (inclui JRE, JVM, compilador `javac`, ferramentas de depuração).
4. **Bytecode (`.class`):** O código intermediário gerado pelo compilador que permite a portabilidade do Java.
