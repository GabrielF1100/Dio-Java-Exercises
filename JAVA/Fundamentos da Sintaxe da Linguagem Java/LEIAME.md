# ☕ Jornada Java - Bootcamp DIO (Itaú - Java com IA)

> *"Aprender não é um evento único, mas um processo contínuo de refinamento."*

## 🎯 Por que compartilhar este repositório?

Mesmo já tendo contato e experiência prévia com Java e lógica de programação, revisitar os fundamentos com um olhar mais maduro faz toda a diferença na formação de um desenvolvedor de software.

Este repositório foi criado com dois propósitos principais:

1. **Revisitar e consolidar a base:** 
   Na pressa de aprender frameworks modernos como Spring Boot ou ferramentas de Inteligência Artificial, muitos pulam ou esquecem detalhes fundamentais da linguagem. Revisitar tópicos como manipulação de tipos primitivos, nuances de operadores, convenções de código (`camelCase`, `UPPER_CASE`), escopo de variáveis e boas práticas de modelagem de métodos nos permite enxergar a linguagem não apenas como comandos, mas como uma verdadeira ferramenta de engenharia.

2. **Aprendizado contínuo e público (Build in Public):** 
   Compartilhar o progresso prático serve como documentação da minha jornada no **Bootcamp Itaú - Java com Inteligência Artificial da DIO**, permitindo que outros estudantes encontrem códigos comentados, ressalvas de pegadinhas clássicas da sintaxe e exercícios resolvidos.
