# Fundamentos da Sintaxe da Linguagem Java - Bootcamp DIO

Este módulo aborda as bases sólidas da sintaxe Java ensinadas na DIO, desde tipos primitivos e operadores até boas práticas de criação de métodos com o projeto guiado **SmartTV**, convenções de nomenclatura e escopo de variáveis.

---

## 📂 Estrutura do Módulo

- **`src/tipos_variaveis/`**
  - [`TiposVariaveis.java`](file:///Users/gabrielfelippebaptista/Downloads/BOOTCAMP/JAVA/Fundamentos%20da%20Sintaxe%20da%20Linguagem%20Java/src/tipos_variaveis/TiposVariaveis.java): Primitivos, limites de memória, conversão/casting e a diferença crucial entre variáveis e constantes (`final`).
- **`src/operadores/`**
  - [`OperadoresPratica.java`](file:///Users/gabrielfelippebaptista/Downloads/BOOTCAMP/JAVA/Fundamentos%20da%20Sintaxe%20da%20Linguagem%20Java/src/operadores/OperadoresPratica.java): Concatenação com `+`, pré/pós incremento, operador ternário, `==` vs `.equals()` em objetos e lógica com curto-circuito (`&&`, `||`).
- **`src/metodos_smarttv/`** (Exercício guiado da aula)
  - [`SmartTv.java`](file:///Users/gabrielfelippebaptista/Downloads/BOOTCAMP/JAVA/Fundamentos%20da%20Sintaxe%20da%20Linguagem%20Java/src/metodos_smarttv/SmartTv.java): Classe que encapsula o estado e comportamento (ligar/desligar, mudar canais, alterar volume).
  - [`Usuario.java`](file:///Users/gabrielfelippebaptista/Downloads/BOOTCAMP/JAVA/Fundamentos%20da%20Sintaxe%20da%20Linguagem%20Java/src/metodos_smarttv/Usuario.java): Classe executável que simula a interação do usuário com a TV.
- **`src/escopo_documentacao/`**
  - [`CalculadoraEscopoDoc.java`](file:///Users/gabrielfelippebaptista/Downloads/BOOTCAMP/JAVA/Fundamentos%20da%20Sintaxe%20da%20Linguagem%20Java/src/escopo_documentacao/CalculadoraEscopoDoc.java): Escopo de bloco vs escopo de método, tags Javadoc (`@author`, `@param`, `@return`) e convenções Java (camelCase, UPPER_CASE).
